# 🍬 Ириска-бот

Телеграм-бот для чата: считает сообщения участников и начисляет **ириски** — местную валюту чата.

## Что умеет

- Считает текстовые сообщения каждого участника (по каждому чату отдельно)
- Начисляет **1 ириску за каждые 100 сообщений** (1000 сообщений = 10 ирисок)
- 🏆 Топ чата за всё время и 📅 топ за последние 7 дней
- Личная статистика: всего / сегодня / за неделю, место в топе, баланс, сколько осталось до следующей ириски
- 📤 Вывод: от **300 ирисок** — бот отправляет писать @PabloSvytoy
- Защита от накрутки:
  - только текст от 3 символов
  - не чаще одного зачёта в 5 секунд
  - не считаются: команды, пересланные сообщения, стикеры и медиа, сообщения через inline-ботов, повтор одного и того же сообщения подряд, запросы к боту («топ», «баланс» и т.п.)
- Админ-команды для выплат и бонусов, журнал всех операций в базе

## Команды

### Участники (в группе)

| Команда | Текстом | Что делает |
|---|---|---|
| `/me` | «стата», «профиль» | Личная статистика |
| `/balance` | «баланс», «ириски» | Баланс ирисок |
| `/top` | «топ» | Топ чата за всё время |
| `/week` | «топ недели» | Топ за последние 7 дней |
| `/withdraw` | «вывод» | Вывод ирисок (от 300) |
| `/help` | «помощь» | Справка |
| `/id` | — | Свой Telegram ID (ответом — ещё и ID автора) |

### Админ (ADMIN_IDS / @PabloSvytoy)

| Команда | Что делает |
|---|---|
| `/take 300` ответом на сообщение участника | Списать 300 ирисок (после выплаты). Так же: `/take @user 300` или ответить текстом **«списать 300»** |
| `/give 50` ответом | Начислить бонус. Так же: `/give @user 50` или **«начислить 50»** |
| `/who` ответом или `/who @user` | Статистика участника |

Все операции записываются в журнал (таблица `ledger` в базе).

## Шаг 1. Создать бота в BotFather

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username → получишь **токен** вида `1234567890:AA...`
2. **ОБЯЗАТЕЛЬНО:** `/setprivacy` → выбери бота → **Disable**. Без этого бот не видит обычные сообщения в группе и ничего не посчитает!
3. Если бот уже был добавлен в группу до отключения privacy — удали его из группы и добавь заново.
4. Добавь бота в свой чат.

## Шаг 2. Настройка

Скопируй `.env.example` в `.env` и заполни:

- `BOT_TOKEN` — токен из шага 1
- `ADMIN_IDS` — твой Telegram ID (напиши боту `/id` в личку после запуска). Пока не заполнено, админ определяется по username из `ADMIN_USERNAMES` (по умолчанию PabloSvytoy)

Все настройки экономики меняются там же: `MESSAGES_PER_IRISKA` (по умолчанию 100), `WITHDRAW_THRESHOLD` (300), `MIN_MSG_LEN` (3), `COOLDOWN_SECONDS` (5), `BOT_TZ` (Europe/Moscow).

## Шаг 3. Запуск

### Локально (Python 3.11+)

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt      # Windows: venv\Scripts\pip
venv/bin/python bot.py                        # Windows: venv\Scripts\python
```

### Docker

```bash
docker compose up -d --build
```

База сохраняется в `./data/iriski.db` — этот файл и есть весь бэкап.

## Шаг 4. Хостинг 24/7

### ⭐ Вариант 1: Amvera — ~290 ₽/мес, проще всего (рекомендую)

Российский облачный сервис под боты: оплата картами МИР, при регистрации дают бонус 111 ₽ на тест, тариф «Начальный» (290 ₽/мес, 500 МБ ОЗУ) боту хватает с запасом.

1. Зарегистрируйся на [amvera.ru](https://amvera.ru), создай приложение (окружение Python)
2. Файл `amvera.yml` уже лежит в комплекте — ничего менять не нужно
3. В настройках приложения добавь переменные окружения: `BOT_TOKEN`, `ADMIN_IDS`, и **обязательно** `DB_PATH=/data/iriski.db` (в `/data` данные переживают пересборку, в папке проекта — нет!)
4. Загрузи код через `git push` или через веб-интерфейс → Собрать → Запустить

Официальный гайд: https://docs.amvera.ru/general/examples/python-tgbot.html

### Вариант 2: свой VPS

Beget — от ~360 ₽/мес (210 ₽ сервер + 150 ₽ IP), Timeweb Cloud — от ~880 ₽/мес. Смысл брать, если на сервере будет жить что-то ещё.

Через Docker: скопируй папку на сервер, заполни `.env`, `docker compose up -d`.

Без Docker — systemd-юнит `/etc/systemd/system/iriska-bot.service`:

```ini
[Unit]
Description=Iriska bot
After=network-online.target

[Service]
WorkingDirectory=/opt/iriska-bot
ExecStart=/opt/iriska-bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable --now iriska-bot
```

### Почему не бесплатно?

Честно: надёжных бесплатных вариантов для 24/7 polling-бота не осталось. Render/Railway/Fly либо стали платными, либо «засыпают» без входящего трафика (а бот на polling его не создаёт). Oracle Cloud Free технически бесплатен, но требует зарубежную карту и регистрация из РФ нестабильна. Реалистичный минимум — ~290 ₽/мес на Amvera.

## FAQ

**Бот не считает сообщения.** В 99% случаев — privacy mode. Проверь шаг 1.2 и передобавь бота в группу. Либо просто сделай бота админом группы — тогда он видит всё независимо от privacy.

**Как поменять ставку или порог вывода?** `MESSAGES_PER_IRISKA` и `WITHDRAW_THRESHOLD` в `.env`, перезапусти бота. Уже начисленные ириски не пересчитываются.

**Как сделать бэкап?** Скопируй файл базы (`data/iriski.db` + соседние `-wal`/`-shm`, лучше при остановленном боте).

**Можно в несколько чатов?** Да, статистика и балансы ведутся по каждому чату отдельно.

**Группа превратилась в супергруппу.** Telegram при этом меняет ID чата, статистика начнётся с нуля. Обычно конвертация происходит в самом начале жизни группы, так что лучше запускать бота уже в супергруппе.
