# PETS WORLD 1.7 — Достижения и недельные рейтинги

## Зачем нужна лига

Новая страница «🏆 Лига питомцев» показывает подтверждённую игровую активность, достижения общего питомца и недельную таблицу лидеров. Дизайн остаётся лёгким и сохраняет Fullscreen Safe Area, основное изображение питомца и пять прежних нижних вкладок.

## Принципы

- Рейтинг **только для питомцев одного Telegram-чата**. Игрок из другой группы не может получить чужой рейтинг по ID.
- Достижения и баллы рассчитываются на сервере из игровых данных SQLite, а не из цифр, переданных браузером.
- Соревнование привязано к календарной неделе по времени сервера (понедельник — воскресенье). Прогресс прошлых недель не становится новым рекордом текущей недели.
- Питомец принадлежит обоим хозяевам. Учитывается деятельность совместного питомца, а не только нажатия одного пользователя.
- Страница только читает историю достижений и результатов. **Никаких дополнительных начислений ирисок и XP за место в рейтинге**: экономика 1.5/1.6 не изменяется.
- Все HTML-тексты, в том числе название питомца, проходят экранирование, чтобы игроки не могли внедрять HTML в рейтинг.
- При выборе другого питомца его данные запрашиваются отдельно; интерфейс не должен показывать устаревшие показатели предыдущего питомца.
- Для оптимизации рейтинги обновляются не чаще приблизительно раза в минуту, можно обновить вручную кнопкой.

## Что проверить на BotHost

1. Скачайте копию `data/iriski.db`, прежде чем устанавливать новую версию.
2. Проверьте зелёный GitHub Actions для PR; объедините его с `main` и выполните «Сохранить и пересобрать» на BotHost.
3. Откройте PETS WORLD в Telegram: фото Барсика и нижняя навигация должны остаться без изменений.
4. Нажмите кнопку «🏆 Лига питомцев» на главной. Должны появиться достижения и рейтинг.
5. У двух хозяев одного питомца достижения совпадают. Нельзя увеличивать опыт или ириски открытием рейтинга.
6. Проверьте рейтинг с другого питомца **того же** чата, а затем из другого Telegram-чата: чужой рейтинг не должен быть доступен.
7. Сделайте реальное игровое действие и обновите страницу рейтинга.
8. Перезапустите BotHost и убедитесь, что весь прежний прогресс и кошельки сохранились.

## Проверки кода

Запуск `python test_pet_league.py` и `python test_miniapp.py` вместе со всем штатным набором GitHub Actions. Работающий `main` не меняется до объединения PR. Дополнительные ключи токена/окружения для страницы рейтинга не требуются.
