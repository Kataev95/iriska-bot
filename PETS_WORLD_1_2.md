# PETS WORLD 1.2 — визуальная обратная связь и анимации

## Этап 1.2 (без изменений экономики)

Успешный интерфейс Fullscreen/состояния питомца из 1.1 сохраняется без изменения расположения: большое изображение, логотип, Safe Area, карточка характеристик и нижняя навигация остаются.

- **Тактильное приветствие** — нажми на изображение питомца: краткая анимация и сообщение, без запроса к API, траты ирисок, повышения настроения или изменения состояния.
- **Реакция на игровой уход** — только после ответа сервера при успешном кормлении/игре/сне появляются короткие эффекты, отражающие действие.
- **Награды** — после фактически подтверждённого получения награды похода или ежедневных заданий появляется краткое визуальное подтверждение. Положительное изменение XP и ирисок вычисляется из двух полученных с сервера снимков; никаких наград на клиенте не начисляется.
- **Новый уровень** — отдельное красивое поздравление при изменении уровня в ответе сервера.
- **Магазин, профессии, гардероб** — лёгкие эффекты при подтверждённом изменении в базе.
- **Задания** — компактная шкала дневного прогресса, учитывающая реальные задания в snapshot.
- **Производительность** — эффекты ограничены 12 элементами, не используют canvas/высокочастотные таймеры, отключают частицы при `prefers-reduced-motion`; CSS применяет только transform/opacity. Не запускаются в скрытом приложении.
- **Безопасность** — никогда не отправляем POST от прикосновения к рисунку. За достижения отвечает только backend SQLite.

## Проверка на телефоне

1. Нажми на фото Барсика — должна быть только анимация, ириски и показатели не меняются.
2. Покорми Барсика (когда доступно) — проверь эффект и кулдаун.
3. Проверь дневные задания — шкала прогресса соответствует реальным трём условиям.
4. После завершения похода забери награду — показываются только **реально зачисленные** XP/ириски.
5. Сменить профессию можно только при наличии прав и нужного уровня. Эффекты не обходят серверную валидацию.
6. Убедись, что кнопки Telegram «Закрыть»/«Свернуть» не налезают на интерфейс. Фото питомца остаётся на главной.
7. При выключении анимаций в настройках ОС частицы не должны двигаться.

## Выпуск

PR содержит только изменения `miniapp/static/*`, тесты и документацию. Без изменения SQLite, серверного API, токена или окружения. После слияния с `main` на BotHost нужно выполнить «Сохранить и пересобрать», затем полностью закрыть и открыть Mini App. Новые параметры `.env` не нужны.
